Local research demo. Not a production system. Not a quarantine/inspection decision tool. Not a biosecurity decision system. The visual model recognizes exactly four genera in a closed-set softmax and has no unknown-class detection. Nothing you upload or enter is stored, and no external API, LLM, or map service is called.

Fruit-fly image + location -> ecological reasoning demo

Image

The image is only held in your browser and this server's memory for the duration of one request. It is never written to disk.

Location (required)

Coordinates you enter are used only for this one request and are never shown on a map or sent anywhere outside this local server.

Observation date/time (optional)

Leave blank if unknown. This demo never guesses a date on your behalf; the geographic model may report less evidence when no date is given.

Environmental/context notes (optional)

These fields are recorded as context for display only. Only "temperature" is currently passed to S3 as a structural covariate; none of these fields change the visual or geographic model scores.
